## About

Nightmare Mode makes the animatronics progressively harder as the night goes on.

The AI levels increase over time, making later parts of each night more difficult.

---

## Features

* **Dynamic difficulty**: Animatronic AI levels increase as the night progresses.
* **Toggle on/off**: Enable or disable Nightmare Mode from the main menu.
* **Custom Night support**: Set your own AI levels for each animatronic.
* **Challenge Nights**: Includes several unique challenge scenarios.
* **Unlock Nights**: Hold `Shift + U` to temporarily unlock all nights. This resets when the game is closed.

---

## Installation

1. Download the latest release from [Releases](https://github.com/D1GQ/NightmareMode/releases) or [GameBanana](https://gamebanana.com/mods/596040).
2. Extract the downloaded files.
3. Copy the files into your **FNAF Rewritten 87** game folder.
4. Launch the game and enable Nightmare Mode from the main menu.
