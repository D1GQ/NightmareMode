# Nightmare Mode

A difficulty mod for FNAF Rewritten 87, The animatronics get more aggressive the longer you survive.

<img width="1920" height="1080" alt="Title" src="/assets/title.png" />

---

## What it does

First few nights feel normal. Then things start ramping up. The longer a night goes, the higher the AI levels climb. No two runs feel the same.

## Features

**Difficulty that adapts** – Animatronics get meaner as the night progresses. New patterns show up each night.

**Toggle on/off** – Button in the top-left of the main menu. Switch back to the original game anytime.

**Custom Night works** – Set your own AI levels for each animatronic.

**Challenge Nights** – Pre-made brutal scenarios if you really hate yourself.

**Skip the grind** – Hold `Shift + U` to unlock all nights temporarily. Resets when you close the game.

## How to install

1. Grab the latest release from [Releases](https://github.com/D1GQ/NightmareMode/releases) or [GameBanana](https://gamebanana.com/mods/596040)
2. Unzip the folder
3. Drag the files into your FNAF Rewritten 87 game folder
4. Launch the game and hit the Nightmare Mode button

**Tip:** Back up your original files just in case.

## FAQ
